# RELAY

**Field Service Operations & Intelligence Platform**

RELAY is a field service management platform designed for maintenance companies to manage their operations, technicians, work orders, and service performance.

## Vision

Help maintenance companies gain better visibility into their operations, improve efficiency, reduce operational costs, and make data-driven decisions.

## Target Market

Medium-sized maintenance companies in Saudi Arabia, initially focusing on HVAC maintenance businesses.

## Core Areas

- Work Order Management
- Technician Management
- Scheduling & Dispatching
- Customer & Site Management
- Maintenance Contracts
- Operational Performance Analytics
- Cost & Profitability Analysis
- SLA Monitoring

## Tech Stack

- Frontend: Next.js, React, TypeScript
- Backend: Node.js, Express.js, TypeScript
- Database: PostgreSQL
- Testing: Jest
- API Documentation: OpenAPI
- Infrastructure: Docker
- CI/CD: GitHub Actions
- Deployment: AWS / VPS (to be decided)

## Project Status

Currently in the Product Discovery and Planning phase.

---

> This project is being developed as a production-oriented software engineering project, focusing on architecture, maintainability, security, testing, and deployment.
